Open source audio identification

Identify music files by how they sound. A free web service, a crowd-sourced database of {% if stats.fingerprints %}{{ stats.fingerprints|compact }} {% endif %}audio fingerprints, and links to MusicBrainz metadata.

Identify your music

If you have an unknown music file, one of the applications using AcoustID, such as MusicBrainz Picard or beets, will very likely be able to tell you what song it is, who wrote it, and a lot more.

In case AcoustID doesn't recognize the song yet, you can help by submitting it to the database, so that the next person trying to identify the same song will have more luck.

Build it into your application

If you are developing an application that needs to identify unknown audio files, you can use the AcoustID web service. It is completely free for non-commercial applications, all you need to do is register your application.

You can also use the service in commercial applications via AcoustID OÜ, which funds the development of the open source project.

How it works

At the core of AcoustID is Chromaprint, an open source library for extracting audio fingerprints. It is optimized for matching near-identical audio, which keeps the fingerprints compact and the extraction fast: a two minute recording becomes about 2.5 KB of data, like this one.

The first two minutes of “{{ sample.name }}” by {{ sample.artist }}. Time runs left to right, each row of pixels is one bit.

The database stores fingerprints submitted by {% if stats.contributors %}{{ stats.contributors|compact }} {% endif %}contributors, grouped into AcoustIDs, and links them to {% if stats.mbids %}{{ stats.mbids|compact }} {% endif %}MusicBrainz recordings. The web service searches it with a custom fingerprint index {% if avg_lookups %}and answers around {{ avg_lookups|compact }} lookups a day{% endif %}.

All of it is open source, the server included, and the database is available for download.
